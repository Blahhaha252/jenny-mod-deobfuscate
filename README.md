# Fapcraft Deobfuscation Project.

This repo contains my ongoing work to manually deobfuscate and reconstruct the source code of an old Minecraft forge 1.12.2 mod.

The goal is to recover readable, understandable java while preserving behavior of the original compiled mod as closely as possible.

## Current status

Work in progress.
